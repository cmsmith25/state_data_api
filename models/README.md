State Data API

A REST API built with Node.js and Express that provides information about U.S. states and supports CRUD operations for state fun facts.

Technologies
Node.js
Express
JavaScript
MongoDB
Mongoose
REST API
Features
Retrieve information for all states
Retrieve individual state information
Retrieve state capitals, nicknames, populations, and admission dates
Retrieve random state fun facts
Add, update, and delete state fun facts
Validate state parameters using Express middleware
Store and retrieve data using MongoDB
API Structure

The application uses a structured backend architecture with separate components for:

Routes
Controllers
Models
Middleware
Database operations
Project Overview

This project demonstrates server-side JavaScript development, REST API design, Express routing, middleware, CRUD operations, and database integration with MongoDB.
